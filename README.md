# Grimcode project template

This repository starts from an implementation specification, not from generated application code.

- `DIRECTIVES.md` contains the owner-controlled project rules.
- `BOILERPLATE_SPEC.md` contains the complete implementation and acceptance specification.
- `docker/adminer/` contains the ready neutral Adminer wrapper and theme that the implementation
  must reuse.
- `AGENTS.md` defines the reading order for coding agents.

The first implementation task is to build and validate the repository described by
`BOILERPLATE_SPEC.md` without introducing a generator or optional feature matrix.
